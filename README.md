# Yu: study

iPad에서 시험지 PDF, 풀이 회차, 오답 및 교재 목차를 관리하는 오프라인 개인 학습 서재입니다. GitHub에 등록하는 파일은 앱 소스, 아이콘과 가상 테스트 코드입니다.

## v0.6.1 · 기존 정답지와 해설지 연결 점검

**자료실 → 필터 및 정렬 → 정답·해설 연결 현황**에서 현재 기기의 등록 파일 수와 연결된 시험지 수를 확인할 수 있습니다.

- **연결 정보 적용**에서 수집 대조표 JSON 또는 원래 수집 ZIP을 선택하면 기기에 있는 PDF의 해시가 일치하는 연결 정보만 적용합니다. 같은 정답표가 여러 과목에 쓰이면 각 과목의 검증 결과가 남습니다.
- **기존 자료 재점검**은 저장된 메타데이터와 문항 분석을 우선 사용합니다. 추가 확인이 필요한 PDF만 한 개씩 읽습니다. 일시중지하거나 다른 앱으로 이동한 뒤 **점검 재개**를 누르면 이어집니다.
- **문제지별 연결 검토**에서 후보와 사유를 확인하고 한 건 또는 여러 건을 선택해 직접 연결할 수 있습니다. 서로 다른 책형·기수·급수와 수집 대조표에서 대조가 필요한 항목은 자동 연결에서 제외합니다.
- **누락·연결 진단 JSON 저장**에는 역할별 등록·연결 수, 기기 내 후보가 없는 자료, 미연결 파일, 보류 사유와 중복 후보가 들어갑니다. 수집 요청 복사는 기기에서 후보를 찾지 못한 항목만 담습니다. 모든 점검은 기기 안에서 실행됩니다.

## v0.6.0 · 문제지와 정답·해설 함께 보기

- **자료실**에서 **문제지 · 정답지 · 해설지**를 전환하고 과목을 누르세요. 카드 제목은 해당 원본을 열고, 카드의 **정답지** 또는 **해설지**는 같은 시험의 연결 자료를 엽니다. 여러 판본은 옆의 펼침 버튼으로 선택합니다.
- **자료 가져오기 → PDF·ZIP 선택**에서 여러 자료를 고르면 등록 전 유형별 수와 검토 대상을 볼 수 있습니다. 파일명·하위 폴더·PDF 머리말과 본문 표식을 확인합니다. 뒤에 해설을 붙인 문제지도 해설 탭에 표시합니다. 스캔본과 정보가 충돌한 파일은 자료 관리에서 직접 확인하세요.
- **자료 관리 → 정답지·해설지 연결**에서 자동 연결, 직접 연결, 연결 안 함을 선택합니다. 직접 연결에서는 여러 해설을 선택할 수 있습니다. 시험 정보나 책형이 불확실하면 **필터 및 정렬 → 정답·해설 연결 현황**에서 확인하세요. 누락 목록 저장과 수집 요청 복사도 이곳에서 합니다.
- 뷰어 상단에서 **문제지 → 해설지 → 문제지**로 돌아오면 각 PDF의 페이지·확대·스크롤 위치와 선택 중이던 오답 번호가 복원됩니다. 오답으로 확정하려면 **선택 저장**을 누르세요. **‹ 뒤로**는 직전 화면과 필터로 돌아갑니다. 홈 화면 앱에서는 왼쪽 가장자리에서 오른쪽으로 쓸어도 됩니다.
- 잘못 분류해 휴지통으로 옮긴 자료는 **자료실 → 휴지통 → 선택 복원** 후 **편집 → 자료 선택 → 분류·파일명 일괄 수정 → 자료 유형 → 해설지 → 적용**으로 옮기세요. 한 개라면 카드의 **자료 관리 → 유형 → 변경 저장**으로 수정할 수 있습니다. PDF와 오답을 보존하며 같은 파일을 다시 가져올 필요가 없습니다.
- **자료실 휴지통**의 원본 영구 삭제와 **오답 휴지통**의 오답 이력 제거는 별도 작업입니다. 원본 삭제 전에 자료 수, 용량, 연결된 문항과 이력을 확인합니다. 다른 시험지가 참조하는 공유 자료는 보존합니다. 삭제 도중 앱을 닫았다면 **자료실 → 휴지통 → 중단된 삭제 확인**에서 남은 항목을 확인합니다.
- 선택적으로 ZIP 최상위에 `manifest.json`을 넣을 수 있습니다. `files` 배열의 각 항목에는 ZIP 안의 `path`, `type`(paper, answer, solution, mixed), 원본의 `sha256`을 적습니다. 해시와 경로가 맞고 확인된 유형과 양립하는 정보만 적용합니다. 일반 PDF·ZIP도 바로 사용할 수 있습니다.

## v0.5.0 · ZIP 하나로 기출문제 등록

1. **자료실 → 자료 가져오기 → PDF·ZIP 선택**을 누르고 파일 앱에서 시험지 ZIP을 고르세요. 여러 ZIP이나 PDF를 한꺼번에 선택할 수 있습니다. 폴더 선택을 지원하는 브라우저에서는 폴더도 가져올 수 있습니다.
2. 신규·중복·오류 수와 예상 용량을 확인한 뒤 **일괄 등록**을 누르세요. 하위 폴더 이름, 파일명, 시험지 머리말에서 과목·연도·시험 종류 등을 읽습니다. 정보가 충돌한 자료는 나중에 **자료실 → 분류 검토**에서 모아 수정할 수 있습니다.
3. 등록한 원본은 바로 사용할 수 있습니다. 이어지는 문항 분석을 멈추려면 **일시중지 → 자료실 열기**를 누르세요. 다시 **자료 가져오기**를 열면 중단한 단계에서 계속할 수 있습니다. 미리보기 단계에서 앱을 닫았다면 아직 읽지 않은 파일에 대해 같은 ZIP을 다시 선택해 주세요.
4. 시험지의 **정답지 열기**에서 연결된 정답을 확인하세요. 정보가 애매하면 **자료 관리 → 분류 검토 · 풀이 상태**에서 정답지를 직접 지정할 수 있습니다. 자료실 **보유 현황**에서 수집할 연도와 시험을 선택하고, 실제로 미등록인 항목을 표시하거나 목록을 내보낼 수 있습니다.
5. **설정 → 저장 공간 관리**에서 원본 용량을 확인하고 **전체 백업 저장**으로 파일 앱에 사본을 보관하세요. 이전 백업을 현재 자료에 추가할 때는 **백업 병합**을 사용하세요. 브라우저가 안내하는 저장 한도는 기기의 남은 용량과 다를 수 있습니다.

### 기존 iPad에서 업데이트 확인

기존에 학습하던 홈 화면 아이콘을 온라인에서 열고 **설정 → 앱 업데이트 → 최신 버전 확인 → 업데이트 적용**을 누르세요. 다른 Yu: study 창이 열려 있다는 안내가 나오면 그 창을 닫고 다시 적용하세요. 앱을 다시 열었을 때 **설정 → 기기 저장 · v0.6.1**을 확인하세요. 기존 아이콘과 사이트 데이터를 유지하면 같은 로컬 서재를 엽니다.

실제 기기에서는 기존 시험지의 마지막 열람 페이지와 오답·테마를 먼저 확인하세요. 이어 작은 ZIP으로 신규 시험지와 동일 PDF 사본을 함께 등록해 중복 수, 정답지 열기, 오답 기록을 확인하세요. 홈 화면 앱을 닫고 비행기 모드로 다시 열어 같은 오답을 열람하거나 A4 미리보기를 생성할 수 있습니다. 대량 파일의 수치와 브라우저별 검증 범위는 [성능 측정 기록](PERFORMANCE.md)에 있습니다.

## v0.4.0 · 시험지 인쇄와 영역 재분석

오답 목록 바로 위의 **A4 PDF 출력**에서 인쇄할 파일을 미리 볼 수 있습니다. 처음 사용할 때는 A4 세로 2단으로 설정됩니다. 100%는 원본 용지를 A4에 비례 축소한 크기입니다. 이전에 저장한 설정도 불러옵니다.

오답 상세의 **영역 재분석**, 또는 **편집 → 영역 재분석**에서 기존 영역과 새 영역을 비교한 뒤 적용하세요. 수동으로 검수한 문항은 **원본에서 직접 수정**으로 편집합니다.

**오답 휴지통** 상단에서 선택 문항이나 전체 이력을 복원하거나 영구 삭제할 수 있습니다. 영구 삭제 확인창에는 문항 수와 이력 수가 표시됩니다. 이전 ZIP을 불러올 때는 기기에 남은 삭제 이력도 적용합니다. 이후 다시 등록한 회차 이력은 별도의 발생 건으로 보관합니다.

## v0.3.0 · 과목별 오답 문제집

1. **오답노트** 상단에서 과목을 누르세요. 숫자는 서로 다른 오답 문항 수입니다. 기존 오답과 새 오답 모두 원본 시험지의 과목을 따릅니다. 자료 관리에서 과목을 수정하면 오답도 이동합니다.
2. **분류별 현황**에서 연도, 교재, PART, CHAPTER 또는 테마를 열거나, **필터 및 정렬**에서 여러 테마와 시험 조건을 조합하세요. 고유 문항, 누적 횟수, 반복 오답, 미숙지 수를 확인할 수 있습니다.
3. 문항을 누르면 추출 영역, 테마, 숙지 상태, 메모 및 회차별 이력이 열립니다. **이 회차 제거** 또는 **이 문항의 전체 오답 이력 제거**를 사용하세요. 잘못 제거한 이력은 **오답 휴지통**에서 복구할 수 있습니다. **편집**에서는 목록 전체 또는 일부를 선택해 숙지 완료, 주 테마 지정, 제거, PDF 출력을 할 수 있습니다.
4. 과목·테마의 현재 목록은 **A4 PDF 출력**, 직접 고른 목록은 **편집 → 선택 PDF**로 여세요. 기본값은 A4 세로, 시험지형 2단, 용지 맞춤 배율 100%입니다. 같은 문항에 여러 테마가 있어도 한 번만 담습니다. **미리보기 생성**을 누르면 실제 파일의 페이지 수와 내용을 확인하고 파일 앱에 저장하거나 공유할 수 있습니다.
5. 출력 세부 설정에서 여백, 간격, 구분선, 원문 출처와 번호, 연속 번호, 교재 정보, 오답 횟수, 메모, 테마별 제목과 정렬을 바꿀 수 있습니다. 문항 상세에서 직접 연결한 정답이나 해설은 부록에 넣을 수 있습니다. 마지막으로 생성한 설정을 다음 출력에 사용합니다.

### 문항 크기와 저장

PDF 포인트로 실제 문항 크기를 계산합니다. 2단에서는 왼쪽 위부터 채우고 오른쪽 단으로 넘어갑니다. 가로가 넓은 지문은 한 줄 전체 폭을 사용합니다. 긴 문항은 저장된 영역이나 빈 줄에서 나누며, 빈 줄을 찾을 수 없는 경계에는 작은 겹침을 두어 내용을 보존합니다. 공통 지문은 좌표로 식별합니다. 자동 인식 영역은 바깥쪽 빈 여백을 다듬고 수동 지정 영역은 지정 크기를 사용합니다.

영역 안에 온전히 들어가는 텍스트와 벡터는 PDF 객체로 보존합니다. 스캔·주석·복합 도형·경계에 걸친 객체는 지정 영역을 무손실 이미지로 그립니다. 목표 해상도는 300dpi이며 매우 큰 영역은 기기의 메모리를 고려해 해상도를 제한합니다. 생성 중에는 취소할 수 있습니다. 문항별 개별 페이지와 원본 페이지 출력도 설정에서 선택할 수 있습니다. 원본 페이지를 선택하면 이웃 문항까지 해당 원본 페이지 전체가 포함됩니다.

### 아이패드에 직접 저장

아이패드에서 선택한 PDF와 학습 기록은 해당 기기의 IndexedDB에 저장됩니다. PC에 등록했던 자료는 PC 브라우저에 보관됩니다. 업데이트는 기존 데이터베이스 이름과 버전 1을 그대로 사용합니다.

홈 또는 자료실의 **PDF 가져오기**를 눌러 파일 앱에서 PDF를 선택하고, 과목과 문항 수를 확인한 뒤 **등록**을 누르세요. 파일 선택기가 화면에 유지되며 읽기·중복 검사·저장 진행 상황이 표시됩니다. 여러 파일은 한 개씩 처리합니다. 등록 후에는 자료실 필터가 초기화되어 새 PDF를 바로 확인할 수 있습니다.

파일을 읽지 못하면 파일 앱에서 PDF를 열어 다운로드를 완료하거나 **나의 iPad**에 복사한 뒤 다시 선택하세요. 오류는 가져오기 창에 표시됩니다. **다시 시도**, **건너뛰기**, **닫기**로 이어서 진행할 수 있습니다. 읽는 동안 **읽기 취소**를 사용할 수 있습니다. 이미 등록한 PDF가 휴지통에 있으면 자료실의 휴지통에서 복구하세요.

Safari의 일반 탭이나 기존 홈 화면 앱을 사용하세요. 일부 비공개 탐색 환경에서는 PDF 저장이 지원되지 않습니다. 문항 자동 인식은 Safari에서 지원하는 스트림 읽기 방식으로도 작동하도록 보완했습니다.

업데이트를 받으려면 인터넷에 연결된 상태에서 앱을 연 뒤 앱 창을 모두 닫고 다시 여세요. 설정에 **기기 저장 · v0.3.1**이 표시되면 새 버전입니다. Safari 데이터 삭제는 기존 학습 기록을 지울 수 있으므로 업데이트에는 사용하지 마세요.

검증은 Chromium 및 WebKit 브라우저에서 진행합니다. `scripts/import-test.mjs`는 터치 기반 파일 선택, 기존 버전 자료 보존, MIME 정보가 없는 PDF, 여러 파일 등록, 중복 파일, 읽기 오류, 저장 공간 부족 시 롤백과 재시도를 검사합니다. `scripts/browser-test.mjs`는 PDF 열람·추출, 백업·복원 및 오프라인 업데이트를 검사합니다. 실제 iPad의 파일 앱과 iCloud 다운로드 동작은 실기기 확인이 필요합니다.

## 설치 및 첫 사용

1. Pages 배포가 완료된 뒤 Safari에서 저장소의 Pages 주소를 열고 첫 설치 시 인터넷 연결을 유지하세요. 공유 메뉴에서 **홈 화면에 추가**를 선택하고 홈 화면 아이콘에서 자료를 등록하세요.
2. **PDF 가져오기**에서 파일을 선택하고 과목, 연도, 시험 종류와 문항 수를 확인합니다. 기본값은 20이며 25 또는 사용자 지정 번호를 입력할 수 있습니다. 원본은 SHA-256으로 중복 검사합니다.
3. 자료실에서 PDF를 열고 틀린 번호를 터치한 후 **선택 저장**을 누릅니다. 현재 회차는 다시 수정할 수 있습니다. 다시 풀 때 **새 회차**를 누르면 반복 오답으로 누적됩니다.
4. **문항 영역 검수**에서 문항 번호를 고르고 인식 영역을 확인합니다. 스캔본이거나 경계가 맞지 않으면 초기화한 뒤 **영역 그리기**로 페이지 위에 드래그합니다. 다른 페이지에서도 영역을 추가할 수 있습니다. **공통 지문 지정**에서 시작·끝 문항을 정하고 원본 위에 한 번 그리면 해당 문항들이 같은 지문을 공유합니다.
5. **설정 → 목차 JSON 가져오기**에서 개인 파일을 선택합니다. 정식 테마와 참조 항목, PART와 CHAPTER 및 교재 페이지를 보존합니다. 오답노트의 문항 상세에서 주 테마와 숙지 상태를 선택하세요.
6. 오답노트에서 과목과 테마 또는 반복 여부를 고르고 **A4 PDF 출력 → 미리보기 생성**으로 현재 목록의 시험지형 문제집을 확인합니다.
7. **분석 및 일괄 분류 → GPT 분류 요청**에서 내용을 확인한 뒤 직접 복사합니다. 응답을 **분류 결과 가져오기**에 붙여넣고 승인할 행을 선택합니다. 화면에서 실행 취소할 수 있습니다. 앱은 원문을 외부에 자동 전송하지 않습니다.

분류 결과 예시 (문항과 테마 ID는 로컬 데이터에 존재해야 합니다).

```json
{"version":1,"results":[{"questionId":"demo#3","primaryThemeId":"demo-theme","secondaryThemeIds":[],"confidence":0.8,"reason":"가상 분류 근거","needsReview":true}]}
```

## 일일 학습 기록

오답노트의 **학습 기록 추출 → ChatGPT 제출용 기록 복사**를 누르면 한국 시간 기준 오늘의 전체 과목 기록을 복사합니다. 기간과 과목을 바꿔 이전 기록도 확인할 수 있습니다. **날짜별 기록 확인 · 정정**에서 날짜를 바꾸거나 잘못된 기록을 취소할 수 있습니다. 텍스트, Markdown, JSON, CSV 저장과 전체 ZIP 백업을 지원합니다.

같은 시험지를 다시 풀었으면 시험지의 **오답 등록**에서 새 풀이 회차를 만든 뒤 문항을 선택해서 저장하세요. 같은 회차의 선택을 다시 저장해도 오답 횟수는 한 번만 집계합니다. 오답이 없었던 회차도 선택 저장이나 풀이 완료 표시를 남기면 학습 기록에 포함됩니다. 오답노트에서 휴지통으로 옮긴 문제의 날짜별 기록은 계속 조회할 수 있습니다.

## 백업과 업데이트

설정에서 **전체 백업 저장**을 눌러 ZIP을 iCloud Drive 등에 보관하세요. ZIP에는 원본 PDF, 개인 기록 및 목차가 들어갑니다. 복원 시 체크섬, ID, 파일 목록과 일부 참조를 검사하고 교체 여부를 묻습니다. 파일과 메타데이터를 한 IndexedDB 트랜잭션에서 교체합니다. 최근 백업 날짜는 다운로드를 요청한 시점입니다. 파일 앱에 저장됐는지 확인하세요.

같은 GitHub 계정, 저장소 이름, URL, 홈 화면 실행 방식을 유지하세요. 설치된 앱 창을 모두 닫았다가 다시 열면 준비된 업데이트를 적용합니다. 서비스 워커는 이 앱의 정적 파일 캐시만 교체합니다. IndexedDB 이름은 `yu-study-archive`, 버전은 2입니다. 기존 보관함은 그대로 열리며 날짜가 남아 있는 오답과 풀이 완료 이력을 `studyLog`에 이관합니다. `files`는 SHA-256 기준 원본 Blob, `meta`는 문서·회차·문항·발생 이력·검수 영역·테마·복습 상태입니다. 향후 버전은 upgrade 트랜잭션에서 기존 자료를 이관해야 합니다. 사이트 데이터 삭제, 기기 손실, 브라우저 저장 공간 회수에 대비해 앱 외부 백업을 유지하세요.

## 개발과 배포

Node.js 22.12 이상에서 `npm install`, `npm test`, `npm run build`를 순서대로 실행합니다. `dist/`만 배포합니다. Vite가 없는 사전 설치 환경은 `YU_DEPENDENCIES`에 pdfjs-dist, jszip, pdf-lib 및 @embedpdf/pdfium이 설치된 node_modules 절대 경로를 지정하고 `node scripts/build.mjs`로 동일 기능의 번들 없는 정적 패키지를 생성할 수 있습니다. HTTP 서버로 /yu-study/ 하위에 마운트합니다.

GitHub 저장소 Settings → Pages → Build and deployment → Source에서 **GitHub Actions**를 선택합니다. main에 push하거나 Actions의 **Test and publish Yu study**를 실행합니다. 테스트와 빌드가 성공해야 배포 단계가 실행됩니다. Vite base는 /yu-study/이고 manifest, worker, 아이콘 및 오프라인 캐시는 프로젝트 하위 경로를 기준으로 합니다. 외부 CDN이나 서버 DB는 사용하지 않습니다.

가상 시험지 렌더 검증은 Chromium과 WebKit에서 실행합니다. 출력 파일을 다시 렌더링해 10pt 글자, 기준선의 물리적 길이, 배치 순서, 선택 범위 밖 표식, 공유 지문과 회전 좌표를 검사합니다. 배포 워크플로의 workbook-render-comparison 아티팩트에서 가상 원본과 출력 PDF·PNG를 비교할 수 있습니다.

Windows 개발과 iPad 홈 화면 설치를 위해 PWA를 선택했습니다. 네이티브 앱은 OS 파일 관리와 직접 통합할 수 있지만 Apple 빌드·서명 환경을 요구합니다. 이 구현은 IndexedDB에 원본을 저장하며 백업 ZIP으로 브라우저 외부에 보존합니다.

## 현재 범위

문항 경계 감지는 텍스트 위치와 번호 순서에 기반한 추정입니다. 스캔, 복잡한 2단, 회전, 공통 지문은 수동 검수가 필요합니다. 마지막 문항이 다음 페이지까지 이어지면 수동으로 추가하세요. 현재 뷰어는 열람 중인 한 쪽을 렌더링합니다. 스캔 자료에서 번호를 찾을 수 없으면 페이지를 직접 선택하세요. 사진·CSV 목차 편집, OCR, iPad 실기기 성능 측정은 후속 범위입니다. 복원과 PDF 생성의 메모리 사용량은 파일 크기에 따라 증가합니다.
